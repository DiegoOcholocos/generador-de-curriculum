# CVWizard Pro — Generador de Currículums Local / Local CV Generator

---

## 🇪🇸 Versión en Español

Este es un potente generador de CVs profesional diseñado para ejecutarse localmente. Permite crear, editar e importar datos de currículums con una vista previa en tiempo real y exportación a PDF de alta calidad.

### ✨ Características

- **Vista Previa en Tiempo Real**: Visualiza los cambios instantáneamente mientras escribes.
- **PDF fiel a la vista previa**: El PDF se genera renderizando el mismo HTML/CSS de la vista previa con un navegador (Playwright/Chromium), así que nunca hay diferencias entre lo que ves y lo que descargas — y los CVs largos ya no pierden contenido: paginan automáticamente a una segunda hoja en vez de cortarse.
- **Multilingüe**: Soporte completo para generar CVs e interfaz en **Español** e **Inglés**.
- **Gestión de Perfiles**: Guarda múltiples versiones de tu currículum (en SQLite) y cárgalas cuando las necesites.
- **Autoguardado**: Tu borrador se guarda solo en el navegador mientras escribes, así que un cierre accidental no pierde el trabajo.
- **Respaldo/Restauración JSON**: Exporta un perfil completo a un archivo `.json` y vuelve a importarlo cuando quieras (útil para mover tu CV entre máquinas).
- **Importación de CSV**: Carga datos masivamente desde archivos CSV con cabecera (columnas identificadas por nombre, no por posición — reordenar columnas en Excel ya no descoloca los datos).
- **Diferentes Estilos**: 11 diseños — 10 combinaciones de color sobre el layout con barra lateral, más una plantilla **ATS de una sola columna** (sin gráficos ni barras de nivel) pensada para pasar los filtros automáticos de selección de personal.
- **Proyectos / Portafolio**: sección dedicada para mostrar proyectos con tecnologías usadas y enlace (GitHub, demo, etc.).
- **Privacidad Total**: Tus datos nunca salen de tu máquina; todo se genera localmente.

### 🚀 Requisitos e Instalación

1. Asegúrate de tener **Python 3.10+** instalado.
2. Instala las dependencias:
   ```bash
   pip install -r requirements.txt
   ```
3. Descarga el navegador que usa Playwright para generar los PDF (solo la primera vez, ~300 MB):
   ```bash
   playwright install chromium
   ```
4. Ejecuta la aplicación:
   ```bash
   python app.py
   ```
5. Abre tu navegador en: `http://127.0.0.1:5050`

Para desarrollo con el depurador de Flask activado (nunca lo actives así en una máquina expuesta a la red):
```bash
FLASK_DEBUG=1 python app.py
```

### 🧪 Tests

```bash
pip install -r requirements-dev.txt
playwright install chromium   # si no lo hiciste ya
pytest tests/ -v
```

Los tests usan una base de datos SQLite temporal y nunca tocan `profiles.db` (puedes forzar la ruta de la base de datos con la variable de entorno `CVWIZARD_DB_PATH`, algo que también usa la suite de tests internamente).

## 🇺🇸 English Version

This is a powerful, professional CV generator designed to run locally. It allows you to create, edit, and import resume data with real-time preview and high-quality PDF export.

### ✨ Features

- **Real-Time Preview**: Visualize changes instantly as you type.
- **PDF matches the preview exactly**: The PDF is generated by rendering the same HTML/CSS as the preview with a real browser engine (Playwright/Chromium), so there's never a mismatch — and long CVs no longer lose content, they flow onto a second page instead of getting silently cut off.
- **Multi-language**: Full support for generating CVs and interface in **Spanish** and **English**.
- **Profile Management**: Save multiple resume versions (in SQLite) and load them whenever needed.
- **Autosave**: Your draft is saved locally in the browser as you type, so an accidental tab close won't lose your work.
- **JSON Backup/Restore**: Export a full profile to a `.json` file and re-import it later (handy for moving your CV between machines).
- **CSV Import**: Bulk load data from header-based CSV files (columns matched by name, not position — reordering columns in Excel no longer scrambles your data).
- **Professional Styles**: 11 designs — 10 color variants of the sidebar layout, plus a single-column **ATS-friendly template** (no graphics or skill-level bars) built to survive automated resume-screening parsers.
- **Projects / Portfolio**: a dedicated section for showcasing projects with the tech stack used and a link (GitHub, live demo, etc.).
- **Total Privacy**: Your data never leaves your machine; everything is generated locally.

### 🚀 Requirements and Installation

1. Ensure you have **Python 3.10+** installed.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Download the browser Playwright uses to render PDFs (one-time, ~300 MB):
   ```bash
   playwright install chromium
   ```
4. Run the application:
   ```bash
   python app.py
   ```
5. Open your browser at: `http://127.0.0.1:5050`

For development with Flask's debugger enabled (never do this on a network-exposed machine):
```bash
FLASK_DEBUG=1 python app.py
```

### 🧪 Tests

```bash
pip install -r requirements-dev.txt
playwright install chromium   # if you haven't already
pytest tests/ -v
```

Tests run against a throwaway temporary SQLite database and never touch the real `profiles.db` (the database path is overridable via the `CVWIZARD_DB_PATH` environment variable, which the test suite uses internally).

## 📁 Estructura del Proyecto / Project Structure

- `app.py`: Servidor Flask (rutas, validación, orquestación) / Flask server (routes, validation, orchestration).
- `themes.py`: Fuente única de temas de color y traducciones de campos del CV / Single source of truth for color themes and CV-field translations, shared by the browser preview and the PDF.
- `storage.py`: Persistencia de perfiles en SQLite (`profiles.db`), con migración automática desde el antiguo formato `profiles/*.json` / SQLite-backed profile storage, auto-migrating from the old `profiles/*.json` layout.
- `pdf_render.py` + `templates/cv_render.html`: Generación de PDF vía Playwright, renderizando la misma plantilla/CSS que la vista previa / PDF generation via Playwright, rendering the same template/CSS as the live preview.
- `static/cv.css`: CSS del propio CV, compartido entre la vista previa del navegador y el documento que se convierte en PDF / The CV's own CSS, shared between the browser preview and the document turned into a PDF.
- `templates/index.html`: Interfaz de usuario (UI) / User Interface.
- `profiles.db`: Base de datos SQLite con los perfiles guardados (no versionada) / SQLite database with saved profiles (git-ignored).

## 🔒 Notas de seguridad / Security notes

- Todos los campos de usuario se escapan antes de insertarse en el DOM (vista previa) o se autoescapa vía Jinja2 (PDF) — no hay HTML/JS arbitrario ejecutándose desde datos de un CSV o perfil importado.
- Los identificadores de perfil se validan contra una lista blanca (`[A-Za-z0-9_-]`) antes de tocar el sistema de archivos o la base de datos.
- Las subidas de fotos tienen un límite de tamaño y se validan como imágenes reales antes de procesarse.
- El depurador de Flask está desactivado por defecto; solo se activa con `FLASK_DEBUG=1`.
